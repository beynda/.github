## How we work

1. **Describe your task.** A rough description is enough; you do not need a technical brief.
2. **Define the first step.** We clarify the scope and what should be built first.
3. **Review working previews.** Follow progress and give feedback as the product takes shape.
4. **Put it into use.** Launch the result and discuss further improvements when needed.
